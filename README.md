# 🍳 AI Recipe Generator

An interactive recipe generator that helps users discover meal ideas based on ingredients they already have at home.

## ✨ Features

- Generate recipe suggestions from available ingredients
- Explore a healthier recipe option
- Copy recipe instructions to the clipboard
- Clear the current recipe and start again
- Responsive layout for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `Ai.html` in your web browser.
4. Enter your ingredients and click **Generate Recipe**.

## 📌 Project Status

This is a beginner-friendly frontend project built to practise HTML, CSS, and JavaScript.
